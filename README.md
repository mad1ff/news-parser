

================================================================================
1. ЦЕЛЬ РАБОТЫ
================================================================================

Целью лабораторной работы является разработка приложения на языке Python 
для автоматического сбора (парсинга) новостей из RSS-лент популярных 
информационных агентств с последующим отображением их в удобном графическом 
интерфейсе пользователя (GUI).

Основные задачи:

    1. Изучить структуру формата RSS (Really Simple Syndication) — 
       стандартного формата для распространения новостных лент в интернете.
    
    2. Освоить методы работы с HTTP-запросами в Python с использованием 
       модуля urllib.request для получения данных с веб-серверов.
    
    3. Научиться парсить XML-документы с помощью модуля xml.etree.ElementTree,
       извлекая из RSS-ленты заголовки, даты, ссылки и описания новостей.
    
    4. Реализовать собственные классы исключений для обработки ошибок:
       - Ошибки сети (NetworkError)
       - Ошибки парсинга (ParsingError)
       - Неверный URL (InvalidUrlError)
       - Отсутствие новостей (NoNewsError)
    
    5. Создать графический интерфейс на базе библиотеки Tkinter с 
       возможностью:
       - Ввода URL RSS-ленты вручную
       - Быстрого выбора предустановленных источников
       - Отображения новостей в таблице
       - Открытия полной статьи в браузере по двойному клику
       - Копирования заголовка или ссылки в буфер обмена
    
    6. Реализовать многопоточность для предотвращения зависания интерфейса 
       во время загрузки данных.

================================================================================
2. ЗАДАЧИ, РЕШЕННЫЕ В ХОДЕ РАБОТЫ
================================================================================

2.1. Разработка модуля исключений (exceptions.py)

    В данном модуле создана иерархия собственных классов исключений:
    
    - NewsParserError — базовый класс для всех исключений парсера
    - NetworkError — ошибки сети (нет соединения, таймаут, HTTP ошибки)
    - ParsingError — ошибки при разборе XML или декодировании данных
    - InvalidUrlError — неверный формат URL (отсутствует http:// или https://)
    - NoNewsError — RSS-лента не содержит новостей

2.2. Разработка модуля загрузки новостей (news_fetcher.py)

    Класс NewsFetcher реализует следующие функции:
    
    - Проверка корректности URL перед запросом
    - Выполнение HTTP GET-запроса с таймаутом 30 секунд
    - Установка заголовка User-Agent для имитации браузера
    - Парсинг XML-данных и извлечение элементов <item>
    - Очистка описания от HTML-тегов с помощью регулярных выражений
    - Обрезание слишком длинных описаний (>150 символов)
    - Ограничение количества новостей (не более 25)

2.3. Разработка графического интерфейса (news_app.py)

    Класс NewsApp предоставляет:
    
    - Окно размером 1100x750 пикселей
    - Поле ввода URL с предустановленным адресом РИА Новости
    - Кнопки быстрого выбора: РИА Новости, Лента.ру
    - Таблицу (Treeview) с тремя колонками: Заголовок, Дата, Описание
    - Полосы прокрутки (вертикальную и горизонтальную)
    - Строку статуса с информацией о загрузке
    - Контекстное меню (правая кнопка мыши) для копирования
    - Двойной клик для открытия ссылки в браузере
    - Фоновую загрузку через threading (интерфейс не зависает)

2.4. Обработка ошибок

    Приложение корректно обрабатывает следующие ситуации:
    - Отсутствие интернет-соединения
    - Недоступность сервера (404, 500 и т.д.)
    - Таймаут при ожидании ответа
    - Неверный формат URL
    - Пустая RSS-лента
    - Некорректный XML

3.1. Функционирующее приложение

    В результате работы создано полноценное приложение, которое:
    
    - Успешно загружает RSS-ленты с сайтов:
      * https://ria.ru/export/rss2/index.xml (РИА Новости)

      * Заголовок (обрезается до 80 символов для таблицы)
      * Дата публикации в формате RSS

    - Позволяет пользователю:
      * Загружать новости из любого RSS-источника
      * Открывать полные статьи в браузере двойным кликом
      * Копировать заголовок или ссылку правой кнопкой мыши
      * Очищать список новостей

В ходе выполнения лабораторной работы были достигнуты следующие результаты:

    1. Успешно освоены методы парсинга RSS-лент с использованием 
       стандартных библиотек Python: urllib.request для HTTP-запросов,
       xml.etree.ElementTree для разбора XML, re для очистки HTML-тегов.
    
    2. Создана модульная архитектура приложения с разделением на:
       - Модуль исключений (обработка ошибок)
       - Модуль загрузки (бизнес-логика)
       - Модуль интерфейса (представление данных)
       - Точка входа (запуск приложения)

       недоступность сервера, неверный формат данных).
    
    4. Создан удобный графический интерфейс с использованием Tkinter,
       включающий таблицу для отображения данных, полосы прокрутки,
       контекстное меню, кнопки быстрого выбора источников.
    
    5. Применена многопоточность (threading) для выполнения длительных 
       операций загрузки в фоновом режиме без блокировки интерфейса.
    
    6. Приложение протестировано на различных RSS-источниках и показало 
       корректную работу с российскими новостными лентами.

Таким образом, все поставленные задачи выполнены в полном объёме. 
Разработанное приложение может быть использовано как инструмент для 
быстрого просмотра новостей из различных источников без необходимости 
посещения каждого сайта отдельно.
